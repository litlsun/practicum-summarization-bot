# practicum-summarization-bot

**Telegram-бот и Colab-блокнот** для автоматической транскрибации, суммаризации аудиолекций и генерации учебных заданий.

Учебный проект, реализуемый совместно с Яндекс.Практикум.

---

## О проекте

Бот и блокнот помогают конвертировать синхронные лекции (аудио и видео) в асинхронный формат:

- Распознают речь и превращают аудио в текст (Whisper Medium)
- Составляют структурированное саммари с ключевыми выводами (Yandex Cloud LLM / Alice AI)
- Генерируют 5 типов учебных заданий с ответами:
  - тест с выбором одного ответа
  - распределение по категориям
  - верно / неверно с объяснением
  - мини-кейс
  - открытый вопрос с опорой на личный опыт
- Поддерживают лекции до 3 часов (рекомендуется)

**Цель:** автоматизация обработки учебных материалов для студентов и преподавателей, перевод синхронного формата в асинхронный.

## Быстрый старт (для пользователя)

1. Откройте блокнот:  
   [`webinar_summarizer_lite.ipynb`](https://github.com/litlsun/practicum-summarization-bot/blob/develop/notebooks/webinar_summarizer_lite.ipynb)
2. Нажмите **Open in Colab**
3. Добавьте секрет `YANDEX_API` с вашим API-ключом Yandex Cloud
4. Вставьте ID папки Yandex Cloud в переменную `YANDEX_CLOUD_FOLDER`
5. Вставьте публичную ссылку на файл с Яндекс.Диска в `YANDEX_URL`
6. Включите GPU: `Runtime → Change runtime type → T4 GPU`
7. Запустите: `Runtime → Run all`
8. Скачайте готовые файлы: `transcription.txt`, `summary.md`, `summary.txt`

Подробнее — в [руководстве пользователя](docs/user-guide_summarizer.md).

## Быстрый старт (для разработчика / запуск бота)

1. Откройте блокнот:  
   [`ya_sum_bot.ipynb`](https://github.com/litlsun/practicum-summarization-bot/blob/develop/notebooks/ya_sum_bot.ipynb)
2. Нажмите **Open in Colab**
3. Добавьте секреты:
   - `YANDEX_API` — API-ключ Yandex Cloud
   - `TG_BOT` — токен Telegram-бота (получить у @BotFather)
4. Вставьте ID папки Yandex Cloud в `YANDEX_CLOUD_FOLDER`
5. Включите GPU, запустите все ячейки
6. Перейдите в Telegram, найдите своего бота, отправьте `/start`
7. Отправьте боту публичную ссылку на файл с Яндекс.Диска

Подробнее — в [гайде разработчика](docs/development-guide.md).

## Пайплайн обработки

1. **Получение файла** — публичная ссылка на аудио/видео с Яндекс.Диска
2. **Транскрибация** — Whisper Medium преобразует речь в текст
3. **Фильтрация** — удаляются организационные фрагменты (просьбы написать в чат, паузы, работа в сессионных залах)
4. **Суммаризация** — Yandex Cloud LLM (Alice AI) генерирует структурированный конспект:
   - тема, целевая аудитория, цель
   - глоссарий
   - основное содержание по блокам
   - выводы
5. **Генерация заданий** — 5 типов с ответами
6. **Сохранение и отправка** — файлы `.txt` (транскрипт и саммари) и `.md` (саммари с разметкой)

## Ограничения текущей версии

- Бот работает только пока открыта вкладка Colab (сессия живёт ~12 часов)
- Поддерживаются только публичные ссылки Яндекс.Диска
- Рекомендуемая длительность лекции — до 3 часов
- Результаты не сохраняются в БД (нужно скачивать сразу)
- Отдельной команды `/tasks` нет — задания генерируются всегда вместе с саммари
