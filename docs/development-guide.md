# Руководство разработчика

## О проекте

Этот документ содержит всё необходимое для доработки, тестирования и поддержки Telegram-бота для транскрибации и суммаризации аудиолекций.

**Стек технологий:**
- Python 3.10+
- `pyTelegramBotAPI` — работа с Telegram
- `whisper` (OpenAI) — распознавание речи
- `moviepy` — конвертация видео в аудио
- Yandex Cloud API + OpenRouter — LLM для суммаризации
- SQLite / PostgreSQL — хранение результатов
