# Руководство разработчика

Этот документ содержит всё необходимое для доработки, тестирования и поддержки Telegram-бота для транскрибации и суммаризации аудиолекций.

## Что делает бот

Бот работает в Telegram: вы отправляете ему публичную ссылку на файл с Яндекс.Диска (аудио или видео), а он возвращает:

- полную расшифровку лекции (TXT)
- структурированное саммари с заданиями (Markdown и TXT)

Бот использует:
- **Whisper (medium)** для распознавания речи
- **Yandex Cloud LLM (Alice AI)** для суммаризации и генерации заданий

---

## Что вам понадобится

1. **Аккаунт в Yandex Cloud**
2. **API-ключ Yandex Cloud**
3. **ID папки (каталога)** в Yandex Cloud
4. **Токен телеграм-бота** (получается у @BotFather)
5. **Компьютер с доступом в интернет**
6. **Браузер** (Chrome, Firefox, Safari)

---

## Шаг 1. Получите API-ключ Yandex Cloud

1. Перейдите в консоль Yandex Cloud: https://console.cloud.yandex.ru
2. Авторизуйтесь (если нет аккаунта — зарегистрируйтесь)
3. В левом меню выберите **«API-ключи»**
4. Нажмите **«Создать API-ключ»**
5. Укажите имя (например, `yashum-bot-key`) и нажмите **«Создать»**
6. **Скопируйте ключ** — он показывается только один раз! Сохраните его.

---

## Шаг 2. Узнайте ID папки (каталога)

1. В консоли Yandex Cloud откройте **«Каталог»**
2. Выберите папку, в которой будет работать бот (или создайте новую, например `yashum-bot`)
3. На странице папки найдите строку **«Идентификатор каталога»**
4. Скопируйте этот ID (строка вида `b1gxxxxxxxxxx`)

---

## Шаг 3. Создайте телеграм-бота и получите токен

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Придумайте имя бота (например, `YaSumBot`)
4. Придумайте username (должен заканчиваться на `bot`, например `yashum_bot`)
5. После успешного создания **скопируйте токен** — он выглядит так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

> ⚠️ Токен нельзя никому показывать. Храните его в секрете.

---

## Шаг 4. Откройте блокнот бота в Colab

1. Перейдите по ссылке на блокнот: [notebooks/ya_sum_bot.ipynb](https://github.com/litlsun/practicum-summarization-bot/blob/develop/notebooks/ya_sum_bot.ipynb)
2. Нажмите **«Open in Colab»**

## Шаг 5. Настройте секреты (API-ключи)

В Colab есть безопасное хранилище секретов — туда вы поместите ключи, чтобы не вставлять их прямо в код.

1. В левой панели Colab нажмите на иконку **🔑 Secrets**
2. Нажмите **«Add new secret»**
3. В поле **Name** введите: `YANDEX_API`
4. В поле **Value** вставьте ваш API-ключ Yandex Cloud
5. Нажмите **«Add new secret»** снова
6. В поле **Name** введите: `TG_BOT`
7. В поле **Value** вставьте токен телеграм-бота
8. Нажмите **«Save»**

> ✅ Готово! Ключи сохранены и будут автоматически подставляться при каждом запуске.

---

## Шаг 6. Вставьте ID папки

Найдите в блокноте раздел **«Суммаризация»** или строку:

```python
YANDEX_CLOUD_FOLDER = ""  # вставьте id папки из консоли Yandex.Cloud
```

Замените пустые кавычки на ваш ID папки:

```python
YANDEX_CLOUD_FOLDER = "b1gxxxxxxxxxxxx"
```

> 💡 Больше ничего в коде не меняйте, если не уверены.

---

## Шаг 7. Запустите бота

### 7.1 Включите GPU

- Меню: `Runtime → Change runtime type` (в русскоязычном интерфейсе: `Среда выполнения → Сменить среду выполнения`)
- В поле **Hardware accelerator** выберите `T4 GPU` (`Графический процессор T4`)
- Нажмите **Save**

### 7.2 Запустите все ячейки

- Меню: `Runtime → Run all`
- Или нажмите `Ctrl + F9` (Windows) / `Cmd + F9` (Mac)

### 7.3 Дождитесь сообщения о запуске

Внизу вы увидите сообщение, что бот запущен (оно может выглядеть как `Bot started` или просто не будет ошибок). После этого ячейка с кодом бота останется активной — **не останавливайте выполнение**!

---

## Шаг 8. Проверьте работу бота в Telegram

1. Откройте Telegram
2. Найдите вашего бота по username (например, `@yashum_bot`)
3. Отправьте команду `/start` — бот должен ответить приветствием
4. Отправьте **публичную ссылку** на аудио- или видеофайл с Яндекс.Диска

Бот начнёт обработку. Через 10–15 минут (для лекции на 1–1,5 часа) вы получите три файла:
- расшифровка (TXT)
- саммари с заданиями (MD)
- саммари с заданиями (TXT)

---

## Шаг 9. Что делать, когда бот обработал лекцию

Бот остаётся в памяти Colab и продолжает работать. Вы можете отправлять ему новые ссылки — он обработает их одну за другой.

**Важно:** Если вы закроете вкладку Colab или отключите компьютер, бот остановится. Чтобы он работал постоянно, нужно развернуть его на сервере.

## Часто задаваемые вопросы

### ❓ Бот не отвечает на `/start`

**Причины:**
- Вы не запустили ячейки в Colab
- Бот остановился из-за ошибки
- Вы закрыли вкладку Colab

**Решение:** Перезапустите блокнот (Runtime → Run all) и проверьте, что в панели Secrets есть оба ключа.

### ❓ Бот отвечает «Нет доступа» на ссылку

Ссылка должна быть **публичной**. На Яндекс.Диске:
- Нажмите на файл → «Поделиться»
- Включите «Доступ по ссылке»
- Скопируйте ссылку заново

### ❓ Бот пишет «Ссылка на папку»

Вы скопировали ссылку на папку, а не на файл. Зайдите в папку, откройте конкретный файл и скопируйте ссылку на него.

### ❓ Бот обрабатывает очень долго (>20 минут для 1 часа)

Проверьте:
- Включён ли GPU (Runtime → Change runtime type → T4 GPU)
- Не слишком ли длинная лекция (рекомендуется до 3 часов)

### ❓ Colab отключается во время обработки

Бесплатный Colab имеет ограничения по времени. Если вы не активны вкладке, сессия может прерваться. Чтобы избежать:
- Оставляйте вкладку открытой
- Периодически кликайте в окно Colab
- Для серьёзной работы используйте платную версию Colab Pro или сервер

### ❓ Бот останавливается, когда я закрываю ноутбук

Это нормально для Colab. Бесплатный Colab работает только пока открыта вкладка браузера.

## Для постоянной работы (развёртывание на сервере)

Если вы хотите, чтобы бот работал 24/7, его нужно развернуть не в Colab, а на сервере.

Альтернативно, вы можете скачать код бота из Colab (File → Download .ipynb) и запустить локально на своём компьютере, но тогда компьютер должен быть включён постоянно.

## Устранение неполадок: частые ошибки

| Сообщение/ситуация | Что делать |
|-------------------|-------------|
| `NameError: name 'userdata' is not defined` | Вы не добавили секреты в панель Secrets |
| `OpenAI authentication error` | Неправильный API-ключ Yandex Cloud. Проверьте секрет `YANDEX_API` |
| `TeleBot: polling exited` | Бот остановился. Перезапустите `Runtime → Run all` |
| Бот не видит команду `/start` | Убедитесь, что вы отправили команду **точно** текстом, не с кнопки (если кнопка не настроена) |
| Файлы не отправляются в Telegram | Проверьте, не превышен ли лимит Telegram на размер файла (бот отправляет несколько маленьких файлов, обычно всё в порядке) |
