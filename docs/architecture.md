## Компоненты
| Компонент | Технология | Назначение |
|-----------|------------|------------|
| Telegram bot | pyTelegramBotAPI | Приём сообщений, отправка ответов |
| ASR | Whisper (medium) | Аудио → текст |
| LLM | DeepSeek через Yandex Cloud | Суммаризация, генерация заданий |
| Чанкирование | кастомная функция `split_text_into_chunks()` | Разбивка длинных лекций |
| БД | SQLite (dev) / PostgreSQL (prod) | Сохранение результатов |

## Поток данных
1. Пользователь отправляет аудиофайл
2. Бот валидирует формат (допустимые: .mp3, .wav, .m4a, .ogg, .mp4)
3. Whisper транскрибирует аудио в текст
4. Если текст > 35 000 символов → чанкирование → суммаризация частей → объединение
5. LLM генерирует саммари в структурированном формате
6. По команде `/tasks N` — генерируются N заданий (1–5)
7. Результат сохраняется в БД с меткой времени

- PythonAnywhere: бесплатно, но ограничен по CPU
