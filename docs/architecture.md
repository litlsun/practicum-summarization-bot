# Архитектура YaSumBot

## Компоненты

| Компонент | Технология | Назначение |
|-----------|-----------|-------------|
| Telegram bot | pyTelegramBotAPI | Приём сообщений, отправка ответов |
| ASR (распознавание речи) | Whisper (medium) | Преобразование аудио/видео в текст |
| LLM (генерация) | Alice AI через Yandex Cloud | Суммаризация, генерация заданий |
| Хранилище секретов | Google Colab Secrets | Безопасное хранение API-ключей |

## Поток данных

1. Пользователь отправляет боту **публичную ссылку** на файл с Яндекс.Диска
2. Бот проверяет ссылку (домен, доступ, тип файла)
3. Файл скачивается во временную папку Colab
4. Whisper транскрибирует аудио/видео в текст
5. Транскрипт отправляется в Yandex Cloud LLM (Alice AI) вместе с системным промптом
6. LLM генерирует:
   - структурированное саммари (тема, цель, глоссарий, блоки, выводы)
   - 5 типов заданий с ответами
7. Результат сохраняется в двух форматах: `.md` (с разметкой) и `.txt` (очищенный)
8. Бот отправляет пользователю три файла:
   - полная расшифровка (`transcription.txt`)
   - саммари с заданиями (`summary.md`)
   - саммари с заданиями (`summary.txt`)
9. Временные файлы удаляются

## Ограничения текущей версии

| Ограничение | Пояснение |
|-------------|-----------|
| Время работы | Colab-сессия живёт ~12 часов, при закрытии вкладки бот останавливается |
| Источник файлов | Только публичные ссылки Яндекс.Диска |
| Длительность лекции | Рекомендуется до 3 часов (дальше возможен таймаут Colab) |
| Отсутствие БД | Результаты не сохраняются — пользователь должен скачать файлы сразу |
| Нет `/tasks` | Задания генерируются всегда вместе с саммари, отдельной команды нет |
