# Руководство пользователя: Суммаризация лекций через Colab

**Версия:** 1.0  
**Назначение:** Преобразование аудио- и видеозаписей лекций в структурированный конспект с заданиями  
**Для кого:** преподаватели, методисты

---

## Что делает этот инструмент?

Вы загружаете ссылку на запись лекции (аудио или видео) с Яндекс.Диска, а инструмент автоматически:

1. **Распознаёт речь** и превращает её в текст (транскрипцию)
2. **Фильтрует организационный мусор** (просьбы написать в чат, технические паузы, работу в сессионных залах)
3. **Создаёт структурированное саммари** с:
   - темой, целевой аудиторией и целью лекции
   - глоссарием ключевых понятий
   - основным содержанием, разбитым на логические блоки
   - выводами и итогами
4. **Генерирует 5 типов заданий с ответами**:
   - тест с выбором одного ответа
   - распределение по категориям
   - утверждения «верно / неверно» с объяснением
   - мини-кейс
   - открытый вопрос с опорой на личный опыт

**Результат** — три файла, которые можно скачать и использовать как готовый учебный материал для асинхронного обучения.

## Что вам понадобится

## Шаг 1. Подготовка ключей доступа

Инструменту нужно разрешение на работу с Yandex Cloud. Это делается один раз.

### 1.1 Получите API-ключ Yandex Cloud

1. Перейдите в консоль Yandex Cloud: https://console.cloud.yandex.ru
2. Авторизуйтесь (если нет аккаунта — зарегистрируйтесь)
3. В левом меню выберите **«API-ключи»**
4. Нажмите **«Создать API-ключ»**
5. Укажите имя (например, `colab-lecture-bot`) и нажмите **«Создать»**
6. **Скопируйте ключ** — он показывается только один раз! Сохраните его в надёжном месте.

> ⚠️ Если потеряете ключ, придётся создавать новый.

### 1.2 Узнайте ID папки (каталога)

1. В консоли Yandex Cloud откройте **«Каталог»**
2. Выберите нужную папку или создайте новую (например, `lecture-summarizer`)
3. На странице папки найдите строку **«Идентификатор каталога»** (ID папки)
4. Скопируйте этот ID.

### 1.3 Что у вас должно быть сохранено

- **API-ключ** — длинная строка вида `AQVN...`
- **ID папки** — строка вида `b1g...`

## Шаг 2. Открытие блокнота в Colab

1. Перейдите [по ссылке]([url](https://github.com/litlsun/practicum-summarization-bot/blob/develop/notebooks/webinar_summarizer_lite.ipynb)) на блокнот
2. Нажмите **«Open in Colab»**

> Блокнот откроется в Google Colab — это бесплатная среда, где код выполняется на серверах Google.

---

## Шаг 3. Настройка секретов (API-ключи)

Здесь вы безопасно передадите ключи блокноту.

1. В левой панели Colab нажмите на иконку **🔑 Secrets**
2. Нажмите **«Add new secret»**
3. В поле **Name** введите: `YANDEX_API`
4. В поле **Value** вставьте ваш API-ключ Yandex Cloud
5. Нажмите **«Add new secret»** снова
6. В поле **Name** введите: `TG_BOT` (оставьте поле Value пустым — этот секрет нужен для совместимости)
7. Нажмите **«Save»**

> ✅ Готово! Ключи сохранены.

---

## Шаг 4. Настройка ID папки

Найдите в блокноте строку:

`YANDEX_CLOUD_FOLDER = ""`

Вставьте ваш ID папки между кавычек:

`YANDEX_CLOUD_FOLDER = "b1gxxxxxxxxxxxx"`

---
## Шаг 5. Вставьте ссылку на лекцию

В самом низу найдите строку:

`YANDEX_URL = ""`

Вставьте публичную ссылку на файл с Яндекс.Диска:

`YANDEX_URL = "https://disk.yandex.ru/i/abc123..."`

**Важно:** ссылка должна быть получена через кнопку «Поделиться», а не из адресной строки.

---

## Шаг 6. Запустите обработку

1. Включите GPU: `Runtime → Change runtime type` → `T4 GPU` → `Save`
2. Запустите все ячейки: `Runtime → Run all`

Дождитесь сообщения «ГОТОВО! Файлы сохранены».

---

## Шаг 7. Скачайте результаты

В левой панели Colab откройте вкладку «Files». Вы увидите три файла:

- `transcription.txt` — полная расшифровка
- `summary.md` — саммари с заданиями (рекомендуемый формат)
- `summary.txt` — саммари без разметки

Нажмите на три точки (⋮) справа от файла → «Download».

## Часто задаваемые вопросы

**Сколько времени занимает обработка?**  
Для лекции на 1,5 часа — около 15 минут.

**Какие форматы поддерживаются?**  
Аудио: .mp3, .wav, .m4a, .ogg и другие.  
Видео: .mp4, .avi, .mov, .mkv и другие.

**Почему ошибка «Нет доступа»?**  
Ссылка должна быть публичной. На Яндекс.Диске нажмите «Поделиться» и включите доступ.

**Почему ошибка «Ссылка на папку»?**  
Вы скопировали ссылку на папку, а не на файл. Зайдите в папку и скопируйте ссылку на конкретный файл.

**Можно ли обработать несколько лекций подряд?**  
Да. После завершения вставьте новую ссылку и снова запустите `Runtime → Run all`.

**Куда сохраняются файлы?**  
Во временную папку Colab. **Скачивайте их сразу** — после закрытия вкладки файлы удалятся.
